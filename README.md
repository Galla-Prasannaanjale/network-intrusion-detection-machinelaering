# Network Intrusion Detection using Machine Learning

This project builds a machine learning model to detect malicious
network traffic using the NSL-KDD dataset.

## Dataset
NSL-KDD

## Algorithms Used
- Logistic Regression
- Random Forest

## Steps
- Data preprocessing
- Feature encoding
- Train-test split
- Model training
- Model evaluation

## Tools
Python, Pandas, NumPy, Scikit-learn, Matplotlib

## Result
Random Forest achieved the best performance in detecting attacks.
